# output/groin_sweep

Results of the two-period groin sweep (M = trapping rate, f = deterioration floor).

## Layout

    <start>_<end>_<preset>/     one directory per sweep
        sweep_results.csv       scored cells, ranked by fillet_err
        sweep_results.jsonl     append-only; one line per cell as it lands
        <combo>/                per-cell shoreline matrix + rate curve
        figures/                that sweep's own diagnostics
    _validation_<period>/       drift-guard reference cell
    figures/                    figures spanning MORE than one sweep
    joint_fit.json / .csv       the fitted (M, f, be1) per preset
    .parameters_pristine.yaml   recovery snapshot (see below)

## Do not move these

Four paths are pinned by code elsewhere. Moving them breaks things quietly
rather than loudly:

| path | pinned by | breaks |
|---|---|---|
| `joint_fit.json` | `HAT_run_all.py`, `HAT_be_zone_LOESS_analysis.py` | stage 6 skips every groin run; the source/sink recalibration silently falls back to a no-groin base |
| `.parameters_pristine.yaml` | `HAT_groin_sweep_worker.py` | no recovery when a killed worker leaves the shared parameter file half-written |
| `_validation_<period>/` | `HAT_groin_sweep.py` | drift guard loses its reference |
| `<start>_<end>_<preset>/` | `sweep_output_dir()` in the config | sweeps stop resuming and re-run everything |

The figures under `figures/` are regenerated by their scripts and are safe to
delete or move.

## Regenerating

    python HAT_groin_sweep_figures.py        # per-sweep diagnostics
    python HAT_groin_sweep_comparison.py     # cross-sweep comparison
    python HAT_groin_position_figure.py      # observed vs modelled position
    python HAT_groin_joint_fit.py --preset edgeBE --preset zeroBE

Rescoring a finished sweep is free -- every cell is on disk, so re-running
`HAT_groin_sweep.py --period P --preset X` skips straight to collation. This is
how a changed observed target is applied without re-running any model.

## One rule

Never run two sweep orchestrators at once. Every CASCADE construction writes
the shared `data/hatteras_init/Hatteras-CASCADE-parameters.yaml`; concurrent
writers corrupt it, and on 2026-08-24 that killed 25 cells of a running sweep.
