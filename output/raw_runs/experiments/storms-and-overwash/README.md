**Parked 2026-10-02: per-domain run-up from beach slope** (Hannah: "I don't want to change it for now"). Not adopted, but it is the one storm-side change that improved overwash skill. There are two ways to take it up:

- **2010–2024 only:** use the 2009-lidar slopes for 2010–2024 and keep 0.06 for 1996–2010.
- **Both windows:** first find a 1990s beach-slope source, so 1996–2010 can be treated the same way.

Either way it needs one storm series per domain in CASCADE (it takes one storm file today; the experiment set them in-process) and re-solved ends. Everything needed to rebuild it is in `2026-10-01-runup-by-slope/`: the slopes are in `tables/beach_slope_by_domain.csv`, and the driver is `scripts/hatteras_ms/experiments/HAT_storm_runup_by_slope.py`.
