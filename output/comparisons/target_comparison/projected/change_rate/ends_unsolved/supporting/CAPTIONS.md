# Captions — ends_unsolved

Written by the figure scripts through `hat_figure_style.caption()`; the images carry no titles or footnotes, this file does.

**`target_comparison_projected_rate_ends_unsolved_1996_2010_2024.png`.** The two candidate targets and the CASCADE hindcast as shoreline change rate over each 14-yr model window by GIS domain (1 at Cape Point, 90 at Pea Island), seaward positive, domain means. Blue: the CoastSat target, the full-period 1996–2024 linear regression rate (the same rate in both windows). Red: the dune-line target, the measured net change between the digitized lines (1997-10-12 to 2009-05-30 (11.6 yr) for 1996–2010; 2009-05-30 to 2023-07-01 (14.1 yr) for 2010–2024; the 2023 date assumed) divided by its interval. Black: the model's own endpoint rate (last annual shoreline minus first, over the 14 run years), the zeroBE run of the same matrix cell, which carries no source/sink term in any domain including the two ends, full management, groin off. The space between the two targets is the beach-width change they imply: solid grey where the beach widened, hatched where it narrowed. Interior GIS 2–89, model minus target: 1996–2010: against CoastSat bias -0.52 m/yr, RMSE 1.42 m/yr; against the dune line bias +1.00 m/yr, RMSE 1.95 m/yr. 2010–2024: against CoastSat bias -0.40 m/yr, RMSE 1.55 m/yr; against the dune line bias -0.37 m/yr, RMSE 1.61 m/yr. The LOWESS-smoothed scores, as the runs are graded, are in tables/skill.csv. One y axis, ±8 m/yr, the same on every figure here.

**`unsolved_run_and_targets_projected_rate_1996_2010.png`.** 1996–2010: the UNCALIBRATED CASCADE run against both candidate targets, as shoreline change rate over the 14-yr model window by GIS domain (1 at Cape Point, 90 at Pea Island), seaward positive; domain means. THE BLACK LINE IS THE SAME RUN IN BOTH PANELS: the zeroBE arm of the matrix cell, which carries NO source/sink term in ANY domain, the two ends included, so every one of the 90 domains is the model's own response and neither target was fitted. The y axis (±8 m/yr) is the same on every m/yr figure in target_comparison. Scores for every model set against every target, raw and smoothed, are in tables/skill.csv.
