# Hindcast parameter sensitivity — figures

Written by `scripts/sensitivity_analysis/plot_sensitivity.py`, which reads the
sweep manifests (`../sensitivity_<year>.jsonl`), `output/raw_runs/run_index.csv`
and each run's own rate CSV. Nothing here is hand-placed — re-running the script
rewrites a directory in place.

## Where to start

**`_comparisons/hs_circularity_1984.png`** — read this one first. It is the whole
argument in a single panel: the same period and scenario swept under both
background-erosion treatments, showing that the apparent best wave height depends
on which one you use.

## Layout

One directory per (period, source/sink preset). Files are numbered in reading
order, so a directory listing is already the order to look at them in.

| file | what it shows |
|---|---|
| `01_skill_overview.png` | interior RMSE (top row) and mean bias (bottom) against each swept value, all five axes side by side. The black diamond is the calibration value, ON the curve. |
| `02_alongshore_wave_height.png` | modelled LRR per GIS domain, one warm line per Hs, over the CoastSat layers. The fan width shows where the island is sensitive to wave height and where it is not. |
| `03…05_alongshore_*.png` | the same, for wave period, asymmetry and high-angle fraction. |
| `06_alongshore_relocation_setback.png` | the same, for the relocation target. Expect the lines to lie on top of each other — this axis moves roads, not shorelines. |
| `08_relocation_outcomes.png` | NC-12 domains drowned and relocations blocked, per relocation target. This is where that axis actually shows up. |
| `summary.csv` | every number behind the figures, one row per cell. |

## The four directories

| directory | cells | what it is for |
|---|---|---|
| `1984_2004_edgeBE` | 28 | **the non-circular period-1 answer.** Background erosion imposed on the two end domains only, so the interior is generated by the physics. |
| `2004_2024_edgeBE` | 28 | the same for period 2. |
| `1984_2004_calibBE` | 28 | the published configuration's fragility. **Not evidence about wave height** — see below. |
| `2004_2024_calibBE` | 4 | a deliberate bracket around Hs 2.5 only (1.8, 2.0, 3.0, 3.5), run to test whether the period-1 calibBE shape reproduced. It did not. |

## Reading the calibBE panels correctly

calibBE fits a per-domain background-erosion rate across 48 domains against the
CoastSat LRR. That fitted field supplies erosion the model would otherwise have to
generate through wave-driven transport, so a calibBE sweep systematically prefers
a **lower** Hs than edgeBE — 2.0–2.5 against 3.0 — and its RMSE minimum says more
about the fit than about the wave climate. Use edgeBE for any claim about a
parameter value; use calibBE only to ask how fragile the published run is.

## The observed layer

Every alongshore panel carries three things, because the target is a hybrid and
plotting only half of it would misstate what the reported RMSE means:

- pale blue scatter — individual CoastSat transect LRRs
- solid blue — LOESS 7-domain and 10-domain smoothings
- dashed navy — **the scoring target**: raw per-domain means over GIS 1–10, where
  LOESS is suppressed near Oregon Inlet, spliced to LOESS-10 over GIS 11–90. It
  sits on top of the LOESS-10 line over most of the island and separates in the
  south, which is exactly where it stops being a LOESS curve.

Skill numbers are interior (GIS 2–89) throughout. The two end domains carry
imposed rates under both presets, so island-wide skill partly scores the boundary
condition rather than the model.
