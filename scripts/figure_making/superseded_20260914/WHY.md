# Retired 2026-09-14

Three sets of figure scripts, kept because each records how something was once
drawn, and none of them is maintained or expected to run.

| Folder | Why |
|---|---|
| `old_dsas_scripts/` | an earlier shoreline comparison, replaced by `shoreline/` |
| `old_plot_tests/` | plots of the CASCADE package's own test scenarios — B3D against the BMI, drowning, parallel runs — not figures of this site |
| `old_rate_analysis/` | the rate analysis that `shoreline/dsas/` replaced |

They were already in `old_`-prefixed folders. This is the same retirement, moved
onto the one idiom the project uses: a dated folder with a note (rule 4 of
`ORGANIZATION.md`). Their paths were deliberately left unfixed — rule 5 skips
retired code, because a complaint about a script nobody will run again buries
the live ones.
