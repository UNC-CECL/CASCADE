# Retired 2026-09-21 — the terminology rename

`projected_vs_duneline.py` built the 1996-2024 LRR x the 25.72 yr dune-line
photo interval against the dune line's measured change. Under the vocabulary
Hannah settled on 2026-09-21, that is TOTAL shoreline change (the rate is
evaluated over the window it was fitted on; only the span is shorter, to
match the photo dates), not a projection.

Its output is reproduced, on the 28 yr calendar span, by
`../total_change_vs_duneline/total_change_vs_duneline.py`, which already
carried the dune-interval numbers as its `*_dune_interval_m` columns. The
old figures are in
`data/hatteras_init/5-scr/4-comparisons/shoreline_vs_duneline/superseded_20260921/`.

Kept for provenance only. Its paths (`PROJECTED_VS_DUNELINE`) no longer exist
in `scripts/site_layer/hat_observed_rates.py`, so it will not run.
