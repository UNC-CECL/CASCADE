# Captions — 4-vs-model

Written by the figure scripts through `hat_figure_style.caption()`; the images carry no titles or footnotes, this file does.

**`overwash_vs_model_1996_2010.png`.** Observed washover against modelled overwash, 1996-2010, the managed run (HAT_1996_2010_edgeBE_offsetmetres_road_bdm_nogroin). (a) One row per image (* = its window starts before the run, so the model covers only part of it); one column per GIS domain. Each image is compared with the model's overwash since the previous image; a model year's overwash is dated by its largest storm, with the 7-day grace of the observed storm table. Dark: both show overwash; purple: observed only; amber: model only; light grey: neither; white: domain not assessed in that image. (b) Domains with overwash per image. (c) The share of images with overwash per domain; the dashed line dates each model year's overwash by every storm in it instead of the largest, an upper bound. Of 803 assessed image-domain cells: 9 both, 60 observed only, 131 model only; the model catches 13% of observed overwash. Washover fades and images are months to years apart, so 'model only' is not by itself a model error. GIS 1 is Cape Point, GIS 90 Pea Island.
