# Captions — 4-vs-model

Written by the figure scripts through `hat_figure_style.caption()`; the images carry no titles or footnotes, this file does.

**`overwash_vs_model_1996_2010.png`.** Washover seen in the imagery against overwash in the model, 1996-2010, the managed run (HAT_1996_2010_edgeBE_offsetmetres_road_bdm_nogroin, storm series v3_split12_trim24). Teal means the model overwashed a domain: dark when the image also shows washover there, light when it does not. Amber is washover the model missed. Light grey: neither; hatched: domain not assessed in that image. (a) Each domain over the whole window: dark teal if model and image agreed in at least one image, else amber if washover was ever seen, else light teal if only the model overwashed (47, 3 and 33 domains; 7 neither). A domain agreeing in one image can still be missed in others: (c) shows each image. NC-12 in black. (b) Domains with overwash in each image, observed and modelled. (c) One column per image, one row per domain; each image is scored against the model's overwash since the previous image (* = that interval starts before the run, so the model covers only part of it). A model year's overwash is dated by its largest storm, with the 7-day grace of the observed storm table. Brackets on the right mark Buxton, Avon and the Tri-Village. Of 803 assessed image-domain cells: 51 both, 18 observed only, 123 modelled only; the model catches 74% of observed washover. Washover fades and images are months to years apart, so 'modelled, not observed' is not by itself a model error. GIS 1 is Cape Point, GIS 90 Pea Island.

**`storms_vs_overwash_1996_2024.png`.** How well the hindcast reproduces the overwash record, 1996–2024 (managed matrix runs, storm series v3_split12_trim24). Each assessed image-and-domain pair is a hit (overwash in the image and the model), a miss (image only), a false alarm (model only) or a correct negative; modelled = overwash > 0 m³/m in a model year whose largest storm falls between the previous image and this one (overwash_vs_model's rule). (a) Every storm the model runs (Duck gauge water level + Stockdon runup, slope 0.06), drawn from the berm (1.34 m MHW, dashed) to its peak and coloured by type (HURDAT2), over the model's own dunes: each domain's lowest dune crest at the end of each model year, 10th–90th percentile across GIS 1–90 (band) and median (line). The 1996–2010 run supplies 1996–2009, the 2010–2024 run 2010–2024 (dotted line). (b) Hit rate = hits / (hits + misses); false-alarm rate = false alarms / (false alarms + correct negatives); skill = the difference (Peirce skill score; 0 = no better than chance, 1 = perfect). 1996–2010: 51 hits, 18 misses, 123 false alarms, 611 correct negatives; 2010–2024: 59 hits, 56 misses, 132 false alarms, 393 correct negatives. (c) Each image's assessed domains by outcome; correct negatives are the rest up to the domains assessed. (d) The share of assessed domains overwashed, observed and modelled, against the largest storm between images; Spearman r with the storm, images assessing ≥ 30 domains only: observed 0.53, modelled 0.79; observed against modelled 0.57. (e) For each domain, the number of images in which it was a hit, a miss or a false alarm, both windows together. (f) Each domain's lowest dune crest in the model, median over the run's years, per window, with the median of each year's largest storm (dashed, same colour): where the crest sits below the dashed line, a typical year's largest storm overwashes that domain. Berm dotted. Images assessing fewer than 30 of the 90 domains (Feb 2022, Apr 2023, Oct 2023) are drawn light in (c) and hollow in (d).
