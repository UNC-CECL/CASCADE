# Captions — 4-vs-model

Written by the figure scripts through `hat_figure_style.caption()`; the images carry no titles or footnotes, this file does.

**`overwash_vs_model_1997_2009.png`.** Washover seen in the imagery against overwash in the model, storm years 1997-2009, the managed run (groin on, HAT_1996_2009_edgeBE_offsetmetres_road_bdm_groin, storm series v3_240). Teal means the model overwashed a domain: dark when the image also shows washover there, light when it does not. Amber is washover the model missed. Light grey: neither; hatched: domain not assessed in that image. (a) Each domain over the whole window: dark teal if model and image agreed in at least one image, else amber if washover was ever seen, else light teal if only the model overwashed (45, 5 and 20 domains; 20 neither). A domain agreeing in one image can still be missed in others: (c) shows each image. NC-12 in black. (b) Domains with overwash in each image, observed and modelled. (c) One column per image, one row per domain; each image is scored against the model's overwash since the previous image (* = that interval starts before the run, so the model covers only part of it). A model year's overwash is dated by its largest storm, with the 7-day grace of the observed storm table. Brackets on the right mark Buxton, Avon and the Tri-Village. Of 714 assessed image-domain cells: 47 both, 21 observed only, 101 modelled only; the model catches 69% of observed washover. Washover fades and images are months to years apart, so 'modelled, not observed' is not by itself a model error. GIS 1 is Cape Point, GIS 90 Pea Island.

**`storms_vs_overwash_1997_2025.png`.** How well the hindcast reproduces the overwash record, storm years 1997–2025 (managed matrix runs, groin on: HAT_1996_2009_edgeBE_offsetmetres_road_bdm_groin, HAT_2009_2025_edgeBE_offsetmetres_road_bdm_nourish_groin; storm series v3_split12_trim24). Each assessed image-and-domain pair is a hit (overwash in the image and the model), a miss (image only), a false alarm (model only) or a correct negative; modelled = overwash > 0 m³/m in a model year whose largest storm falls between the previous image and this one (overwash_vs_model's rule). (a) Every storm the model runs (Duck gauge water level + Stockdon runup, slope 0.06), drawn from the berm (1.34 m MHW, dashed) to its peak and coloured by type (HURDAT2), over the model's own dunes: each domain's lowest dune crest at the end of each model year, 10th–90th percentile across GIS 1–90 (band) and median (line). The calibration run (1996 DEM) supplies 1997–2009, the test run (2009 DEM) 2010–2025 (dotted line). (b) Hit rate = hits / (hits + misses); false-alarm rate = false alarms / (false alarms + correct negatives); skill = the difference (Peirce skill score; 0 = no better than chance, 1 = perfect). 1997-2009: 45 hits, 23 misses, 38 false alarms, 608 correct negatives; 2010-2025: 30 hits, 127 misses, 35 false alarms, 499 correct negatives. (c) Each image's assessed domains by outcome; correct negatives are the rest up to the domains assessed. (d) The share of assessed domains overwashed, observed and modelled, against the largest storm between images; Spearman r with the storm, images assessing ≥ 30 domains only: observed 0.54, modelled 0.69; observed against modelled 0.51. (e) For each domain, the number of images in which it was a hit, a miss or a false alarm, both windows together. (f) Each domain's lowest dune crest in the model, median over the run's years, per run, with the median of each year's largest storm (dashed, same colour): where the crest sits below the dashed line, a typical year's largest storm overwashes that domain. Berm dotted. Images assessing fewer than 30 of the 90 domains (Feb 2022, Apr 2023, Oct 2023) are drawn light in (c) and hollow in (d).

**`overwash_timeline_1997_2025.png`.** Where and when the model overwashed, against the 19 images of the overwash record, storm years 1997–2025. Managed runs, groin on (HAT_1996_2009_edgeBE_offsetmetres_road_bdm_groin, HAT_2009_2025_edgeBE_offsetmetres_road_bdm_nourish_groin; storm series v3_split12_trim24). (b) Each image is a framed pair on its date. Left half: teal where the model overwashed the domain (any overwash > 0) since the previous image, matched as overwash_vs_model scores it: a model year counts toward the first image after its largest storm, with the 7-day grace of the observed storm table. Right half: the image, black where it shows washover, grey where it was assessed and shows none, hatched where the domain was not assessed. So a storm and the image that recorded it sit side by side however late the imagery came (Isabel, Sept 2003, pairs with May 2004). For the first image of each run (Oct 1997 and Aug 2011) the interval starts before the run, so the model covers only part of it. Faded behind the pairs: the model's overwash per model year, filling its calendar year because Barrier3D records overwash per year, not per storm. Ticks on the top edge mark the image dates; the dotted line is where the calibration run (1996 DEM) gives way to the test run (2009 DEM), named in the header band. Storms named above: the hurricanes and nor'easters (NE) with the highest water levels in the model's storm series, at their peak dates. (a) For each image, the domains the model overwashed since the previous image (teal) and the domains the image shows overwashed (black), both over the domains the image assessed. (c) Each domain's share of images showing washover (black) and of model years with any overwash (teal). GIS 1 is Cape Point, GIS 90 Pea Island.
