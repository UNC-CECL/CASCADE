# Captions — sites

Written by the figure scripts through `hat_figure_style.caption()`; the images carry no titles or footnotes, this file does.

**`shoreline_position_window_fits_forward_from_1996.png`.** The record the sweep is fitted on. Every CoastSat shoreline position at one transect in each of eight evenly spaced domains, 1996 to 2024, with the annual median through them and some of the 25 nested fits drawn as straight lines, each spanning the window it was fitted on and labelled with its moving year. Every window starts 1996. Purple is 1996–2024, the reference every window converges on. Where the lines separate, the rate still depends on where the window is cut. Position is CoastSat chainage, seaward positive, on an origin that is arbitrary per transect: only the SLOPE compares between panels, and each panel is autoscaled.
