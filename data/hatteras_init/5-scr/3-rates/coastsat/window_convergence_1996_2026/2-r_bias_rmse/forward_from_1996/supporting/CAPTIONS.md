# Captions — forward_from_1996

Written by the figure scripts through `hat_figure_style.caption()`; the images carry no titles or footnotes, this file does.

**`window_profiles_r_forward_from_1996.png`.** How the CoastSat shoreline change rate profile of each window (OLS, all 906 transects, domain 1 at Cape Point to 90 at Pea Island) compares with the 1996–2026 profile, against window length. Alongshore Pearson r: whether the hotspots are in the same places (shape only). Red: windows with the start pinned at 1996 (1996–1997 … 1996–2026). At 20 years (1996–2015, the model window) r = 0.80 (0.72–0.85). r stays at or above 0.5 from 11 years; 0.75 from 19 years; 0.9 from 26 years. The windows are nested in the reference, so every score reaches its perfect value at 31 years by construction. Shading is the 95% interval from 1000 bootstrap resamples of the 90 domains (domains, not transects, because neighbouring transects move together). The dashed vertical line marks the model window (1996–2015, 20 yr). The dotted lines are r = 0.5, 0.75, 0.9, conventional levels, not ones the data pick out; circled points are the model window and the first window length from which r stays at or above each level. The top axis gives the calendar window.

**`window_profiles_bias_rmse_forward_from_1996.png`.** How the CoastSat shoreline change rate profile of each window (OLS, all 906 transects, domain 1 at Cape Point to 90 at Pea Island) compares with the 1996–2026 profile, against window length. (a) Bias: the mean over transects of window rate minus 1996–2026 rate; negative means the window is more erosional than the long-term record. (b) RMSE: the root-mean-square of the same difference, the typical size of the miss at one transect, sign ignored (RMSE² = bias² + scatter²). Red: windows with the start pinned at 1996 (1996–1997 … 1996–2026). At 20 years (1996–2015, the model window) bias -0.59 m/yr (-0.77 to -0.39), RMSE 1.14 m/yr (1.00–1.28). The windows are nested in the reference, so every score reaches its perfect value at 31 years by construction. Shading is the 95% interval from 1000 bootstrap resamples of the 90 domains (domains, not transects, because neighbouring transects move together). The dashed vertical line marks the model window (1996–2015, 20 yr). Circled points are the model window. The y-axes are cut at ±2.5 m/yr and 6 m/yr; the shortest windows run past. The top axis gives the calendar window.
