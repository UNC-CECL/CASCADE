# The flat build — retired 2026-09-15

The `1984` offsets as they stood **before the per-start builds were
versioned**. `2-brie-offset/README.md` calls this "the flat build a start had
before it was versioned": one set of files per start year, with no `v1`/`v2`
beneath it and no `CURRENT` pointer.

On 2026-09-15 the versioned layout replaced it, and `v1` was built from
`duneline_1984.geojson` against zero domain GIS 78. `PROVENANCE.md` in the
parent records `v1` as "compared with `superseded_20260915_flat`" — this
folder is that comparison's other side, which is the reason to keep it.

It is also what `2-brie-offset/README.md` means by "the earliest build that
has a match across every build, which for 1984 and 2004 is the superseded flat
one".

Nothing here is maintained. Rule 4 of `ORGANIZATION.md`: retirement is a dated
folder with a note, and deletes nothing. Note added 2026-09-22; the folder and
its date are unchanged.
