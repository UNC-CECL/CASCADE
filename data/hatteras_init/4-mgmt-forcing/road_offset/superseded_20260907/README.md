# dunestart_offset ARCHIVE — 1984-start / v1

Road offsets and setbacks measured against **1984-start `v1`** interior row 0,
frozen 2026-09-03 immediately before the v3 re-pick overwrote them in place.

Kept because `dune-topo/v2` was built on these numbers: its
`HAT_seaward_row_insert_audit.csv` reports `setback_raw_before_m` from this
measurement, and without the archive v2 stops being reproducible the moment the
live files are rebuilt on v3.

`RoadOffset_1984_domains.csv` here is the file that says GIS 85 = −10 m.
The live file after the re-pick says something else, because row 0 moved.

Only 1984 was archived. 2004 reads `2004-start`, which the re-pick did not touch.
