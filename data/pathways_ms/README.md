# pathways_ms — field data for the pathways manuscript

**A different site and a different study.** Nags Head morphometrics, 1997 to
2019, one file per survey year. Nothing in the Hatteras hindcast reads any of
it; it belongs to `scripts/other_ms/pathways_ms/`.

It sits here rather than under `hatteras_init/` because that tree is the
Hatteras model's inputs and nothing else, and it sits here rather than beside
its scripts because data does not live in the code tree (rule 1 of
`ORGANIZATION.md`). Moved 2026-09-13.
